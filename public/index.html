How to add an item

Open Master Inventory → Add New Item → Enter Item Name, Category, Unit, thresholds → Save.

How to enter production

Open Production → Select date → Choose item → Enter quantity in whole numbers or fractions → Submit.

How to record stocks in

Open Stocks In → Enter item → quantity → source/reason → Save.

How Night Operations works

Open Night Operations → Choose item → Review beginning, production, and stocks in → Enter physical ending count → Submit. The system calculates actual usage automatically.

How usage is calculated

Beginning + Production + Stocks In = Total Available

Total Available - Physical Ending = Actual Usage

How to read the dashboard

Dashboard shows totals, low stock, critical low, replenishment required, and recent activity.

How to backup

Use the Export Items button or export from the browser to save CSV files.
